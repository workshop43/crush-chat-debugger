# 测试用聊天样例

一组「整活」风格的样例对话，用于测试诊断器。
直接复制对应代码块里的内容，粘贴到页面 **STEP 3** 即可。

> 「预期诊断」列出的是大致走向，可用来验证判定校准是否正常——
> 单方面发力、对方冷处理的应偏红，对方有互动的不应被无脑判死刑。

---

## ① 土味情话连环 call

**预期诊断**：`CRITICAL` / `流失预警` / `不予转正` / `Pass`（对方机械防御）

```
我：你猜我想吃什么？
对方：什么？
我：你猜。
对方：不猜。
我：吃你家的饭，做你家的人。
对方：我家不缺人。
我：那缺不缺一个每天给你讲冷笑话的？
对方：缺一个会闭嘴的。
我：巧了，我闭嘴的时候特别帅。
对方：那你试试。
```

## ② 发癫文学

**预期诊断**：`CRITICAL` / `流失预警`（单方面上头，对方泼冷水）

```
我：救命，我刚路过奶茶店想到你了。
对方：嗯？
我：因为你也很甜，而且我也想花钱买你。
对方：我不卖。
我：那我求购，挂闲鱼我蹲一辈子。
对方：你今天是不是没睡好。
我：睡好了，梦里都是你，醒了想接着睡。
对方：建议多喝热水。
```

## ③ 舔狗一字回

**预期诊断**：`CRITICAL` / `Pass` / `予以毕业`（经典一字回，结尾已读不回）

```
我：在吗？
对方：在。
我：哈哈没事，就想看看你在不在。
对方：哦。
我：你今天过得开心吗！开心我也开心！
对方：还行。
我：不开心也告诉我，我可以表演节目。
对方：不用。
我：节目准备好了，叫《我有多喜欢你》，时长一辈子。
对方：[已读不回]
```

## ④ 双向抽象对线

**预期诊断**：`WARNING` / `增长停滞` / `观望`（对方有来有回还接得住梗）

```
我：我决定了，今天追到你。
对方：哦，那你失败了。
我：失败是成功它妈，我明天再来。
对方：你妈知道你这样吗。
我：知道，她说让我把你领回家。
对方：领养请走正规渠道。
我：好的，请问您的领养条件是？
对方：先把你这张嘴上交。
```
